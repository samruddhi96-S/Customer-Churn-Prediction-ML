# Customer-Churn-Prediction-ML
# 📊 Telecom Customer Churn Prediction (End-to-End Data Science & ML)

## 📌 Project Overview
This end-to-end Data Science project analyzes customer behavior in the telecom industry to identify key drivers of customer attrition (churn) and builds a **Random Forest Classifier** to predict high-risk customers.

## 🔍 Key Insights & Findings
- **Dataset:** 7,032 customer records analyzed across 20 demographic, account, and service features.
- **Contract Impact:** Month-to-month contract customers have significantly higher churn rates compared to 1-year and 2-year contracts.
- **Tenure & Charges:** Customers with shorter tenure and higher monthly charges are most likely to leave.
- **ML Model Performance:** Achieved **~78.5% accuracy** using a Random Forest Classifier, with **Tenure, TotalCharges, and MonthlyCharges** emerging as the top predictive features.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-Learn
- **Environment:** Google Colab & GitHub
